# 视觉素材

`round-tree.webp` 与 `favicon-tree.png` 取自用户上传照片中的圆形树状标记，保留原照片的角度和质感。

`borderwise-mark.png` 和 `favicon-dark.png` 使用为 Borderwise 原创绘制的银灰色几何徽记。

旧版金色菊花标记是根据瑞雲殿的内卷厚瓣和下垂外瓣绘制的插画。[品种造型参考 · 日本国立历史民俗博物馆](https://www.rekihaku.ac.jp/kids/schedule/garden/o151103.html)

`river-entrance.webp` 是上一版玄关使用的舟中人物画，由用户提供。
