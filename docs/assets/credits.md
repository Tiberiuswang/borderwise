# 视觉素材

`saihoji-entrance.webp` 来自用户上传的第二张西芳寺照片，由原始 JPEG 转为 WebP。页面按视口裁切构图。

品牌菊花标记是根据瑞雲殿的白色内卷厚瓣和下垂外瓣绘制的插画。[品种造型参考 · 日本国立历史民俗博物馆](https://www.rekihaku.ac.jp/kids/schedule/garden/o151103.html)

`saihoji.webp` 和 `saihoji-mobile.webp` 是旧版背景素材，由 Motokoka 拍摄。桌面版已缩放并转为 WebP，移动版另有裁切。两个衍生文件均按 CC BY-SA 4.0 授权。
